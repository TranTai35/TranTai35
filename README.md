- MQTT protocol between the device and the web app
- Flask dashboard with history charts, remote control, Firebase storage and email alerts

### 🕵️ [Griductive Solver](https://github.com/TranTai35/griductive-solver)

A playable 2D deduction game with a logic engine that only gives a verdict when it is logically entailed by the public clues.

- Self-implemented **DPLL SAT solver** with unit propagation and backtracking
- CNF encoder for several clue types, uniqueness checking and deduction traces
- Six sample cases, hint and auto-solve modes, unit tests

![Python](https://img.shields.io/badge/-Python-3776AB?style=flat-square&logo=python&logoColor=white)
